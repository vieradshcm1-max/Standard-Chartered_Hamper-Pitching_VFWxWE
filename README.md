# Standard Chartered Tết 2027 Landing Page

Landing page pitching bộ quà Tết 2027 “Vun bồi thịnh vượng” dành cho Standard Chartered Việt Nam.

## Đưa lên GitHub Pages

1. Tạo một repository mới trên GitHub.
2. Upload toàn bộ nội dung trong folder này vào nhánh `main`.
3. Mở **Settings → Pages**.
4. Trong **Build and deployment**, chọn **Deploy from a branch**.
5. Chọn nhánh `main`, thư mục `/ (root)`, rồi nhấn **Save**.

Website là trang tĩnh, không cần cài đặt hoặc chạy lệnh build.

## Cấu trúc

- `index.html`: nội dung landing page.
- `styles.css`: thiết kế và responsive.
- `app.js`: menu, hiệu ứng cuộn và hoạt ảnh mở đầu.
- `assets/`: logo và hình ảnh sản phẩm.
